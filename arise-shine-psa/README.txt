ARISE & SHINE DIGITAL WORLD - PSA FULL-STACK VERSION

STEP 1 - Install XAMPP
1. Start Apache and MySQL in XAMPP.
2. Copy the entire arise-shine-psa folder into C:\xampp\htdocs\

STEP 2 - Create the database
1. Open http://localhost/phpmyadmin
2. Click Import.
3. Select database.sql from this project.
4. Click Go.

STEP 3 - Add your existing images
Copy your existing "my image" folder and image picture.png into the project root if you want to keep the old logo/working image.

STEP 4 - Open the website
http://localhost/arise-shine-psa/index.php

STEP 5 - Admin dashboard
http://localhost/arise-shine-psa/admin/login.php
Default login:
Username: admin
Password: admin123

IMPORTANT: Change the default admin password before putting the project online.

FEATURES
- Responsive order form
- Orders saved to MySQL
- Admin login/session
- Admin dashboard
- Add product + image
- Delete product + image
- View customer orders
- Update order status
- Product images automatically appear on the public website
